# Custom Compact

When this command is run, do the following in order:

1. Update .claude/handoff.md with:
   - What we completed this session
   - What is currently in progress
   - Next steps
   - Any unresolved issues

2. Update .claude/decisions.md with any new decisions made 
   this session that aren't already logged

3. Update the "Current Focus" section of CLAUDE.md to reflect 
   where we are now

4. Then run the built-in /compact to compress conversation history

Confirm when all files have been updated before compacting.
